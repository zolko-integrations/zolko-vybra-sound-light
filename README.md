# ZOLKO × VYBRA Sound & Light — Landing de cotizaciones

Landing page de **VYBRA Sound & Light** ("Tu evento, otra vibra"), renta de sonido e iluminación para eventos en Guadalajara, Jalisco. Desarrollada por **ZOLKO INTEGRATIONS**.

> Estado: **prototipo**. No está publicada en ningún dominio. Se publica solo con autorización de Lulú y con fotos reales del equipo.

## Qué hace

- Muestra los 3 paquetes de 5 horas con su flyer: Essential ($2,990), Party ($3,990) y Experience ($4,990), en MXN.
- Tiene un formulario de cotización que arma el mensaje y abre WhatsApp (33 1840 8880). Antes de enviarlo, el cliente ve una vista previa.
- Tiene una sección **Aliados VYBRA** para quien quiera recomendar el servicio a cambio de una comisión en efectivo. Las condiciones se acuerdan directo por WhatsApp.
- El campo "¿Quién te recomendó?" permite saber a qué aliado le toca cada renta.

## Importante

- **No guarda datos.** No tiene servidor ni base de datos: solo prepara un mensaje de WhatsApp.
- Los precios y lo que incluye cada paquete salen de los flyers de VYBRA (19 nov 2026). Cualquier cambio necesita aprobación.
- Las imágenes de `img/` son los flyers oficiales. Sus fotos son de referencia, no del equipo real.

## Estructura

```
index.html      Página completa (HTML, CSS y JS en un solo archivo)
img/            Flyers de los 3 paquetes
```

## Cómo verla

Abre `index.html` en el navegador. Para publicarla gratis se puede usar GitHub Pages o Netlify, pero solo con autorización.
